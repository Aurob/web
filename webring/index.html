This website is a part of a custom webring system that I created. The source code can be found here

Each site in this ring is a website that I control, either directly via self-hosting or through a third-party like with GitHub or NeoCities.

At the footer of each page on each site in the ring, you will find a previous, random, and next button. The previous and next will take you to in a loop through each of the sites. The random button will take you to a random site in the ring.
